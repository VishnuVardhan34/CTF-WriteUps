# picoCTF Writeups

A comprehensive collection of writeups for **picoCTF** challenges, covering all categories including Binary Exploitation, Cryptography, Forensics, Reverse Engineering, Web Exploitation, and General Skills.

This repository serves as a learning resource for cybersecurity enthusiasts, red teamers, and CTF beginners. Each writeup includes a step-by-step walkthrough, tools used, and solution explanation — **without revealing flags in plaintext** (to encourage hands-on learning).

## Contribution
Contributions are welcome! If you have a unique solution or improved explanation:
1. Fork the repo
2. Add your writeup in the appropriate category
3. Open a pull request with a clear description

**Enjoy learning and happy hacking!**
